# GRID

## Mapping the Future of Printing.

---

## Vision

> "To be the essential **digital printing partner in the global market**, making the transition from digital design to physical reality effortless and stress-free for every user."

## Mission

> "To **revolutionize the printing experience** by combining precision technology, high-quality output, and seamless logistics, empowering professionals and students to focus on their craft."

## Goal

> "To become and lead the digital printing industry within the Philippine market in the span of **three to five years**."

## Beta Testing Demands

### User Experience & Data

1. **Data Mining** — Add a "Request a Feature" button or area / special instructions to add more features in the app.

2. **Funnel Efficiency** — Track where users stop their journey through the app to assess possible problems in the system.

3. **User Profiling** — Identify which market segment is most targetable. Add different user profiles (e.g., Construction Worker, Office Worker, Student).

### Logistics

4. **Logistics Assessment** — Using a single rider model; integrate a **batched delivery system** and third-party apps for users outside Davao.

5. **Multi-Destination & Split Ordering** — Allow users to send their prints to multiple different delivery areas in one order.

6. **Scheduling System for Logistics** — Allow users to schedule when their printout will be delivered.

### File Validation & Printing Preferences

7. **Uploaded File Information & Validity** — Admin-side check to verify if the uploaded file matches the selected print option (e.g., file is A3 size but the user selected A4). Add a warning to prompt users to correct their print type.

8. **Architectural Renders / Files — Image Format Preference** — Detect whether an uploaded file is in **CMYK or RGB format**, as this heavily impacts print output quality.

9. **Architectural Digital Ruler (File Checking)** — Add a digital ruler or visual proof feature to confirm that uploaded file dimensions are in the correct scale or size.

10. **Printing Preferences** — Add a file setting preference for users to choose between **"Fit to Paper"** or **"Actual Size"** printing.

### Privacy & Trust

11. **Auto-delete / Purge Button** — Allow users to delete their uploaded files after printing to establish trust and protect user privacy.

### Notifications

12. **Notification System** — Improve the current notification system with the following sub-features:
    - **a. Job Order Tracking** — Push notifications to the user during social media usage to update them on their order status.
    - **b. SMS Integration Notification** — Allow users to receive notifications via SMS even when they are offline.
    - **c. Daily Marketing & Regular Updates Notification** — Send regular notifications to keep the app top-of-mind for users.

### Payments

13. **Payment System** — Direct integration with **GCash** for payments. Additionally, introduce a **GRID Credit Top-Up System** allowing users to pre-load credits to their account to avoid needing to open GCash each time.

### 3D Printing System

14. **3D Printing System**
    - **a. Admin/User Manual Status Bar** — Since 3D printing timelines can be unpredictable, allow admins to manually input a temporary estimated completion status (e.g., "8 hours before completion").
    - **b. 3D Printer Limitations** — Enforce size limits based on hardware:

      | Printer        | Build Volume                |
      | -------------- | --------------------------- |
      | Bamboo A1      | 25.6 cm × 25.6 cm × 25.6 cm |
      | Bamboo A1 Mini | 18 cm × 18 cm × 18 cm       |

      Display a warning to users if their model exceeds the printer's build volume. Offer a **live chat** option for personalized/custom requests.
